# UVM_Interpreter_Variant26 - Ассемблер и Интерпретатор для Учебной Виртуальной Машины (Вариант №26)

## 1. Общее описание

Данный проект реализует ассемблер и интерпретатор для Учебной Виртуальной Машины (УВМ) согласно Варианту №26.

Спецификация УВМ:
* **Размер команды:** 11 байт.
* **Архитектура:** Регистрово-адресная с полями A, B, C, D (в зависимости от команды).
* **Память:** Единая (команд и данных).

## 2. Описание языка ассемблера (JSON)

Для человекочитаемого представления программы используется формат **JSON** (список инструкций). Каждая инструкция представляет собой словарь с ключом `"op"` (название команды) и полями-аргументами.

| Команда | Описание | JSON Поля (Аргументы) |
| :--- | :--- | :--- |
| **LC** | Загрузка константы | `"const"` (значение B), `"addr"` (адрес C) |
| **RM** | Чтение значения из памяти | `"src"` (адрес B), `"dst"` (адрес C) |
| **WM** | Запись значения в память | `"src"` (адрес B), `"dst"` (адрес C) |
| **BR** | Унарная операция `bitreverse()` | `"src_base"` (адрес B), `"dst"` (адрес C), `"offset"` (смещение D) |

**Пример (из `test_program.json`):**
```json
[
    {
        "op": "LC",
        "const": 862,
        "addr": 457
    },
    {
        "op": "RM",
        "src": 317,
        "dst": 486
    },
    {
        "op": "WM",
        "src": 850,
        "dst": 879
    },
    {
        "op": "BR",
        "src_base": 117,
        "dst": 402,
        "offset": 43
    }
]
